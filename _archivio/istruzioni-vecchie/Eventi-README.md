# Cartella "Eventi & Catering"

Stessa convenzione già usata per Aziende / Motori / Sport — non serve altro codice, basta seguire questi passaggi:

1. Metti le foto a piena risoluzione qui dentro, numerate in ordine: `Eventi-1.jpg`, `Eventi-2.jpg`, `Eventi-3.jpg`, ...
2. Metti le miniature (versione leggera, stessa numerazione) dentro `thumbs/`: `thumbs/Eventi-1.jpg`, `thumbs/Eventi-2.jpg`, ...
3. Apri il file HTML del sito, cerca `galleryConfig` nello script, e aggiorna il numero `count` della voce `Eventi` con il totale delle foto che hai caricato.

Fatto questo la card "Eventi & Catering" in home passa automaticamente da segnaposto "In arrivo" a card cliccabile con copertina, e la galleria si popola da sola — nessun altro intervento necessario.

Questo file può essere cancellato quando la cartella avrà foto vere.
